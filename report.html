Data and method

How MicroMatch works

  1. Read the addressFrom REA or Domain, or entered by the user.
  2. Match the homeCheck unit, street number, street and suburb within the City of Sydney.
  3. Get the factsThe proxy requests live Microburbs data. The API key stays on the server.
  4. Apply the quizThe saved profile sets the weights. The panel shows the score and reasons.

What the four pillars tell you

  • Commute. Nearby transport, work distance and parking help you judge everyday travel.
  • Safety. Local modelled crime and mapped hazards help you decide what to check before an inspection.
  • Lifestyle. Nearby shops, cafés, gyms and green space show what daily life could look like.
  • Price. Compare rent with weekly income or estimated value with a purchase budget.
Scoring, sources and missing data
  • MicroMatch reads only the listing address. The matcher checks the local address index when available and can query the Microburbs geocoder.
  • The panel prompts for confirmation when the match is uncertain. A saved quiz profile and exact match are required to show the fit score.
  • The scorer averages the available signals within each pillar and combines the pillars using quiz weights. It skips missing signals and scales the remaining weights.
  • Pros and cons show their source and date when available. Rent uses a usable recorded advert, then a block or suburb median for the property type.

Run the extension

Try it locally

  1. Use the repository checkout with Chrome or Chromium, Node.js, npm and Python 3.
  2. Copy proxy/.env.example to proxy/.env and set your team’s MICROBURBS_API_KEY.
  3. Run ./run.sh from the repository root in Bash on macOS or Linux, or in WSL on Windows.
  4. Open chrome://extensions, enable Developer mode, and select Load unpacked. Choose the extension folder.
  5. Once the servers are running, open the local MicroMatch website, sign up and complete the quiz. Then open a City of Sydney listing and click the MicroMatch toolbar icon.

Market comparison

What buyers already see

  • REA and Domain show listing details and offer property profiles with history and estimates where available. REA profiles · Domain price guide
  • Homer and Property Seeker add pricing context such as guides, price history or estimates. Homer · Property Seeker
  • MicroMatch shows how the facts affect someone’s own fit score and lets them open each pillar to see why.

What remains uncertain

Limits of the recorded checks

  • The automated browser runs used archived pages after the portals blocked automated requests. The latest demo used live Microburbs lookups for the property facts.
  • Travel distances are straight-line estimates. Incomplete workplace addresses sometimes failed to resolve.
  • On the Victoria Park Parade unit, hazards, social-housing estimate, buy affordability and comparable value were unavailable.
  • Area rent medians group homes by property type. They can include homes with different bedroom counts.
