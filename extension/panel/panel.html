Static mock-up at the panel's 360 px width, styled by panel.css. Every address here is made up, and each dashed box is a placeholder for a component's output. The extension uses only the template above; nothing in this preview ships.

How the extension uses this file

  • Only <template id="mbx-result-template"> is used. This preview, its demo- classes and the inline style block never reach a listing page.
  • Frames show the panel unclipped. In the extension the body scrolls inside the fixed panel, under the existing header.
  • The check line always states the verdict in words (Exact, Close or Weak match), so its modifier colour is never the only signal.
